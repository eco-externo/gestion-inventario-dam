# 🖥️ Sistema de Gestión de Inventario (Desktop)

Proyecto de escritorio desarrollado en **Java** utilizando **JDBC** para la persistencia de datos con **MySQL**, orientado como parte del portfolio académico del ciclo formativo de Desarrollo de Aplicaciones Multiplataforma (DAM).

## 🚀 Características principales
* **Arquitectura CRUD completa:** Gestión de altas, bajas, modificaciones y consultas de productos y stock.
* **Conexión a Base de Datos relacional:** Uso de MySQL mediante conexiones seguras con JDBC.
* **Interfaz Gráfica intuitiva:** Diseñada para ofrecer una experiencia de usuario fluida y eficiente en entornos de escritorio.
* **Control de excepciones:** Gestión robusta de errores de conexión y validación de datos de entrada.

## 🛠️ Tecnologías utilizadas
* **Lenguaje:** Java (JDK 17 o superior)
* **Base de datos:** MySQL / phpMyAdmin
* **Conectividad:** Driver JDBC (`mysql-connector-j`)
* **IDE:** IntelliJ IDEA
